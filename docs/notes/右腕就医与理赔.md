# 看诊时接着问

前面的影像讨论围绕右腕 TFCC 和关节稳定性展开。后续应把医院书面方案补进来，尤其记清这些问题的回答：

- 手术主要解决疼痛、弹响，还是不稳定？

- 具体修复哪里？哪些能在术前确认，哪些要术中决定？

- 如果建议尺骨短缩，医生给出的具体依据是什么？

- 哪些情况会临时改变术式，术前同意的范围是什么？

- 耗材用什么型号、费用怎样，术后多久能打字和提重物？

聊天中的术式推测，不能记成医生已经确定的方案。

# 理赔时接着核实

我在误工费讨论中明确说过：**休假期间基本工资正常发放。**因此，后续需要把实际收入变化、休假证明和各项费用材料放在一起，而不能只保存一个估算金额。

仍待核实的问题包括：误工期限和收入损失怎样证明，保险不赔的项目由谁承担，哪些费用可以分阶段处理，以及赔偿计算采用什么时间和标准。
