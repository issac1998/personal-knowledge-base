# 怎样把事情说清楚

**删掉重复的信息，保留解释事情所必需的因果。**这是上次表达训练里最值得记住的一点。

# 同一个动作不必说两遍

原句：

> 我想完成身份验证，但因为账户被锁定，所以无法完成身份验证。

可以改成：

> 账户被锁定，我暂时无法完成身份验证。

“无法完成”已经说明了当前问题，再补一次“我想完成”通常没有增加信息。

# 有些重复是为了说清关系

我曾遇到的银行流程问题更复杂：身份验证要先设置电话理财密码，但账户锁定后无法设置；重置密码又要求先完成身份验证。

这里两次提到“身份验证”有不同作用，不能为了少重复一个词，把循环关系删掉。

可以这样说：

> 更换手机后，我需要重新验证身份。客服要求先设置电话理财密码，但账户被锁定，无法设置；重置密码又需要先完成验证，两个流程互相卡住了。

# 下次可以直接套用

**反馈卡点：**现在做不了什么 → 卡在哪里 → 需要对方怎样协助。

**叙述经过：**原本要做什么 → 遇到什么障碍 → 后来怎样。

检查时问自己：删掉这一句后，别人还能完整理解吗？如果能，它可能多余；如果因果、时间或新结果丢了，就要保留。
