# 就医与检验原始数据

本目录保存当前可见医疗资料的逐项转录。门诊162条（2021-01-13起），原始检验991项、逐药处方137条、影像13项及病理1份。三个漏存门诊卡片已补齐，门诊数与App累计162次一致。正常和异常指标均保留。完整覆盖边界及仍缺原件见[coverage.md](coverage.md)。线上索引为[就医病历与检验指标总览](https://chatgpt.com/space/page_4f8b3ee504208191ba115605f3fc0812)。

- `encounters.csv`：每次已读门诊的日期、机构、科室、诊断、处理和恢复信息。
- `lab_results.csv`：长表格式，每行一个指标，保留单位、参考范围和异常标记。未显示参考范围的项目留空。
- `historical_values.csv`：后续门诊病历中转述的旧检验值，和已读原始报告分开保存。
- `imaging_reports.csv`：影像报告结论和日期差异。
- `source-notes/`：按日期转录的报告及病历要点，并保留哪些内容来自医生记录、哪些来自检验页面。
- `trends.md`：可比指标的时间序列和仍待核对的数据。
- [健康建议与长期跟踪](health-advice-2026-11-09.md) 汇总多次接近边界、反复异常及已回到参考范围的指标，并按疾病列出复查重点。
- `medications-and-follow-up.md`：病历中出现的用药、治疗与复查安排；区分医生医嘱和病历描述的实际使用。

日期含义分别记录：就诊日期、标本采集日期与报告日期不混用。不同机构的参考范围可能不同；表中“正常”仅表示位于该次报告自己的参考范围内，不能单独说明没有健康风险。缺失值用空白表示，不补零。没有读到的治疗和恢复情况写“未见记录”，不推断为未治疗或已康复。

## 快速查阅

打开[健康记录查阅台](health-hub.html)，可搜索药名、疾病、医院与指标，按年份筛选，并查看同项指标变化。原名称和单位保留，统一归组映射见canonical_analytes.json。先看[下次就诊建议](next-visit-plan.md)确认近期联系事项。

预约和实际用药的个人补充只保存在当前浏览器，可导出备份供后续更新，不会自动同步知识库。基线数据仍以CSV及知识库原记录为准。查阅台已完成本地逻辑检查；真实浏览器显示受本地文件访问限制，已请本人打开核对。当前用药、最近注射、术后预约和结核评估结果待本人补充。
